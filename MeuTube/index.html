Canais

Cole o link do canal, o @handle, o ID (UC…) ou o link de qualquer vídeo do canal. Você pode adicionar vários de uma vez, separados por vírgula. Somente vídeos destes canais aparecem no app. Ative “Apenas lives” num canal para que ele não apareça no Início nem na lista de canais — só em “Ao vivo”, quando estiver transmitindo.

    Credenciais da API

    Como obter essas credenciais
    1. Acesse o Google Cloud Console e crie (ou escolha) um projeto.
    2. Em “APIs e serviços › Biblioteca”, ative a YouTube Data API v3.
    3. Em “Credenciais”, crie uma Chave de API (restrinja-a ao domínio do app).
    4. Configure a “Tela de permissão OAuth” e crie um ID do cliente OAuth do tipo “Aplicativo da Web”, adicionando a URL do app (ex.: http://localhost:8080) em “Origens JavaScript autorizadas”.
    5. Abra o app por http:// ou https:// — o login e o player não funcionam abrindo o arquivo direto (file://).
