Credenciais da API

Como obter essas credenciais
  1. Acesse o Google Cloud Console e crie (ou escolha) um projeto.
  2. Em “APIs e serviços › Biblioteca”, ative a YouTube Data API v3 e, para a sincronização na nuvem, a Google Drive API.
  3. Em “Credenciais”, crie uma Chave de API (restrinja-a ao domínio do app).
  4. Configure a “Tela de permissão OAuth” e crie um ID do cliente OAuth do tipo “Aplicativo da Web”, com a URL do app (ex.: https://esiojunior89.github.io) em “Origens JavaScript autorizadas” e https://esiojunior89.github.io/MeuTube/ em “URIs de redirecionamento autorizados”.
  5. Para entrar em outros aparelhos sem digitar nada, coloque o Client ID e o servidor de login em DEFAULT_CONFIG, no arquivo config.js. Depois do login, canais, opções, chave de API e progresso vêm da nuvem.
  6. Abra o app por https:// — o login e o player não funcionam abrindo o arquivo direto (file://).
